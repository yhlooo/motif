# 单文件 diff 的滚动阈值

按用户要求，少于 200 个展示行的文件 diff 完整展开，使用页面纵向滚动；达到 200 行时启用文件内部纵向滚动，沿用 760px 最大高度。

阈值按实际渲染的 patch 行计算，包含 diff 头、hunk 标识、上下文及增删行；忽略未渲染的空字符串，不把末尾换行算作额外一行。行内评论不计入阈值，不会因为增加评论而让较小的 diff 突然变成内部滚动区。长代码行仍可横向滚动。

实现将高度限制移到按阈值添加的 diff-scrollable 类，沿用原来的代码行、评论锚点和文件树跳转逻辑。

验证：13 项现有前端测试、JavaScript 语法检查及 git diff --check 通过。实际 Chrome 在 1440px、390px 下检查 199、200、201 行边界，纵向内部滚动分别为关闭、开启、开启；199 行文件加入长评论后仍完整展开，评论浮层不跳动、不出屏，文件树跳转正常，无横向页面溢出或脚本错误。
