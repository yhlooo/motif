# 列表内容区的创建审查入口

根据用户反馈，将“创建审查”从全局顶栏移入列表内容区的“代码审查”标题行。标题在左侧，状态筛选和创建按钮在右侧，与列表宽度对齐。窄屏允许换行，避免横向溢出。空列表也保留这个入口。

创建属于列表操作，单个审查详情不提供创建入口。详情渲染替换列表内容时，按钮随列表一并移除；返回全部审查后重新显示。

脚本保留初始创建按钮的元素引用。创建成功切入详情后，表单提交的 finally 仍可恢复这个元素的状态，不会因为按钮已经离开 DOM 而查询到 null。

沿用原创建表单、自动预览和校验机制。验证使用现有前端测试及页面脚本语法检查，并通过浏览器检查列表入口位置、窄屏布局和创建后详情不显示入口。
