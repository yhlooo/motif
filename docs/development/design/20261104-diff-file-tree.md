# Diff 右侧文件树

## 用户决定与边界

用户要求在 diff 右侧增加默认展开、可折叠目录的文件树。每个可见叶子节点（文件或折叠目录）显示新增及删除行数，样式参考 GitHub。

文件树只导航当前选中批次或连续合并批次的 diff，不增加仓库文件浏览功能，不改变审查、批准、评论或文件 diff 顺序。视觉与交互参考见 [调查记录](../research/20261104-diff-file-tree.md)。

## 实现

- 使用现有 diff API 的 path、path_base64、patch、binary 和文件采集范围信息，不新增 API 或持久化字段。
- diffLineStats 仅统计 hunk 内的增加与删除行，忽略 diff 头、上下文及无末尾换行提示。二进制或范围外文件的文本行数不参与汇总，以星号及悬停/无障碍说明标注。
- buildDiffTree 按原始路径字节分目录，避免显示路径转换导致文件身份混淆；目录和文件使用不同键，支持删除文件与同名新增目录同时出现在一次 diff 中。非 UTF-8 路径片段以字节转义显示，文字通过 textContent 写入。
- 文件树按目录优先、名称排序，diff 本身保持原顺序。统计自叶子向父目录汇总，展开目录的统计隐藏，折叠时显示其全部后代文件的增删数。
- 所有目录初始展开，使用原生 details/summary。点击文件滚动并聚焦对应 diff，树中显示当前点击项；不改写 review hash，不触发审查刷新。
- 文件名只占一行并在超长时省略，悬停显示完整文件路径。目录缩进最多按六层递增，避免深层路径挤掉行末计数。
- 桌面使用 diff 主列与 260px 右侧文件树，文件树 sticky 且内部可滚动。1100px 以下文件树移到 diff 上方并限制高度，保证窄屏代码不被三列挤压。空 diff 不显示文件树。
- 切换批次或合并范围时，树与新 diff 在同一渲染中替换；目录恢复默认展开，不保存跨范围的折叠状态。

## 验证

- 10 项前端脚本测试通过，包括 hunk 统计、目录汇总、多加号代码行、二进制及范围外文件、目录/文件同名、排序后跳转原文件、默认展开、Unicode 与非 UTF-8 路径。
- `go test ./internal/transport/web`、JavaScript 语法检查及 `git diff --check` 通过。
- 独立无头 Chrome 在 1440px 和 390px 下验证九个文件、多级目录、长路径、纯增删、二进制和特殊字符：默认展开、折叠目录汇总、点击跳转及保留 review hash、行评论入口、切换批次后文件树和统计更新均通过，页面无横向溢出及脚本错误。桌面截图确认文件树在 diff 右侧，窄屏检查确认其在 diff 上方。

## 吸附导航与弱边界样式

用户要求滚到顶部后左右导航保持可见，并将文件树改为与整体配色协调、弱边框的设计。

- 左侧分批栏采用 sticky/top:0、align-self:start 和 100dvh 最大高度，内容过长时独立滚动。重新渲染分批选择时恢复原 sidebar.scrollTop，避免长批次列表回到开头。
- 桌面文件树也采用 top:0 和 100dvh 最大高度。1100px 以下放在 diff 上方时仍吸附，高度最多 30dvh/320px。
- 760px 以下分批导航高度为 25dvh/180px 中的较小值；文件树吸附在其下方，高度也以相同上限约束。两者不会相互覆盖，剩余视口用于阅读 diff。
- 文件跳转的 scroll-margin-top 根据导航布局补偿，避免目标文件头被顶部导航挡住。吸附仍受所属区域边界约束。
- 文件树使用与页面一致的浅灰绿底色，去掉圆角外框及标题分隔线，只保留 1px 淡左边线。目录图标改为柔和灰绿，悬停和选中使用浅色背景。

吸附机制调查见 [研究记录](../research/20261104-review-sticky-navigation.md)。10 项前端测试通过；实际 Chrome 在 1440px、1024px、390px 下用 50 个分批和 35 个文件分别滚动到 1800px、3800px，验证导航位置不再上移、左右内部滚动可用、切换分批保留侧栏位置、文件跳转避开导航，均无横向溢出或页面错误。截图检查确认无外框、淡左边线和一致底色。
