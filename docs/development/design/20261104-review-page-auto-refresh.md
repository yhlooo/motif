# 审查页面自动检查更新

用户确认移除审查详情中的“刷新审查”按钮，以浏览器刷新页面触发更新检查。

现有启动流程读取 `#review=<id>`，调用 `openReview`，先 POST `/api/code-reviews/{id}/refresh`，再 GET 已发布的审查内容。从列表打开详情也走同一流程。因此本次仅移除重复按钮，沿用现有更新机制。

更新失败时继续读取最后一次已保存的审查范围，展示失败原因；不清空已保存内容、批准或评论。不新增后台轮询，也不将 GET 读取改为隐式更新。

验证：前端现有测试、JavaScript 语法检查通过；使用模拟 DOM/接口执行完整页面脚本，检查带审查 hash 的启动请求顺序，以及更新失败后继续展示保存内容。
